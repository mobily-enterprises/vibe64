# Talk with Colleague

Open Colleague with its avatar button in the page header. It opens a drawer on
the right; on a small screen it uses the available width. Closing the drawer
keeps your draft and conversation.

The larger face stays at the top right while messages scroll, with a smaller
size on mobile. Text wraps around it and uses the wider space below. Close is
the compact X at the top left; there is no separate name/project heading. The
face and message box stay in place while you read earlier messages.

Type in the message box, then click Send. With a nonempty draft, Tab moves
directly from the text field to Send and Enter sends the message. While Colleague
is working, the same shortcut uses Steer to add instructions. Stop stops its
current turn. These controls and the model picker sit inside the message box.
The model picker is unavailable during a turn or while sending.

Reply text appears progressively while Colleague is answering. Hosted clients
receive live updates with periodic refresh as recovery. Only the completed answer
is saved. Live updates and refreshes keep the same conversation and expanded
messages in place; a voice-enabled host can begin speaking readable phrases while the
answer is still growing. Stop or new
steering clears the unfinished reply. Reopening the drawer while it is working
shows the current reply again. Tool requests are not displayed as chat text.

When the host supplies voice, the microphone and read-aloud controls also appear
inside the message box. Recognized words update one Pending user message in
the chat; acceptance replaces it with the saved message without duplicating it
or changing your typed draft. Unsent or discarded words are not saved history.
Live voice status and preview text also appear above the message box,
without shifting the box or buttons. Microphone permission and recording require
your interaction; Colleague can explain the controls but cannot grant permission
or press them for you.
Live turn interpretation requires an available **Helper** for the selected
workflow. Online checks this when you choose **Start live conversation**, before
opening the microphone. Missing assignments are reported before loading the
model catalogue. A setup failure leaves recording off; you can still use
**Talk to Colleague** or hold the avatar to record manually.
In **AI Accounts**, choose **Configure routing** beside that workflow,
select a compatible **Helper**, then **Save routing**. The same controls apply
on desktop and mobile; scroll the routing dialog on a small screen. Unsupported
choices are disabled, and an unsupported saved choice shows why it cannot run.
Included Big Pickle can be selected for Helper as well as chat. Live voice
uses the existing OpenCode request format and the task’s existing permissions. Colleague can inspect routing and, when asked, change permitted
assignments; connecting an account or granting access requires the owner.
If routing is unavailable, Colleague explains the reason and setup step. If
interpretation fails, finish and review the recording before sending; unfinished
words do not authorize work.
