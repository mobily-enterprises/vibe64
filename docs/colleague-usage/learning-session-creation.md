# Opening a saved learning conversation

On an installation that supports Learning mode, opening a lesson conversation
uses your exact saved lesson attempt and your authorized AI connection. Reopening
that attempt retains the same conversation and history. It does not create a
practice project for a lesson without an exercise, reset progress or send a
message to the teacher merely by opening the conversation.

If opening fails after a connection or page-update error, inspect the saved
attempt before retrying. An uncertain result can already have created its
conversation; reopening the same attempt checks that record before creation.
If the lesson has ended or its active progress is not confirmed, resolve that
state before opening new work. Retained history remains separately readable.

Colleague can explain this recovery and offer supported lesson operations. It
must not substitute a new project, a different lesson attempt or another person's
conversation. A missing connection or missing lesson support is a real error.

These action and storage prerequisites do not yet expose a complete lesson picker
or Main teacher in every installation. They do not establish successful question
delivery, assessment, speech or presentation. Use the installation's supported
controls; an internal operation name is not a visible button.
