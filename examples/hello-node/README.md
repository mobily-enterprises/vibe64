# Hello Node

A complete Genesis example with no application dependencies, database, accounts,
or external services. Run `npm start`, open `http://127.0.0.1:3000`, and edit
`index.html`. Reload to see changes. Run `npm test` to verify its HTTP behavior.

The authored Blueprint, Stack, collaboration and engineering settings, subsystem
map, and Program are in `genesis/`. Vibe64's example launcher uses the installed
Genesis initializer to add the current agent skills and provider hooks to the
working copy before committing its initial baseline.
